# FUEL UP 营养引擎

一个本地优先的增肌、减脂营养记录工具，支持商品营养换算、每日餐盘、身体档案、训练消耗估算、DeepSeek 营养建议以及日/周/月趋势记录。

## 使用方式

直接在浏览器中打开 `index.html` 即可。页面数据保存在浏览器本地存储中。

## DeepSeek

点击 AI 教练区域的设置按钮，填写自己的 DeepSeek API Key。密钥只保存在当前浏览器中，不会写入本仓库。

## 数据记录

- 每日热量、蛋白质、碳水、脂肪和膳食纤维随餐盘自动保存
- 晨起体重每天记录一次
- 支持日、周、月视图和 CSV 导出
- 热量缺口按“估算总消耗 - 当日摄入”计算

## 跨设备同步

点击页面右上角的同步按钮：

1. 在电脑上创建同步码，并将现有数据上传。
2. 在手机或其他设备输入同一个同步码。
3. 所有设备会在本地修改后自动上传，并在重新打开页面时拉取云端更新。

云端仅保存 AES-GCM 加密后的数据，同步码不会上传。DeepSeek API Key 不参与同步，需要在每台设备单独填写。

## 部署

本项目为纯静态网页，可直接通过 GitHub Pages 托管。
